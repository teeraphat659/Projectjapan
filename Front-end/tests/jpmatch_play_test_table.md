# ตารางทดสอบหน้าเล่นจับคู่

เปิดหน้า `Front-end/data/jpmatch.php` หลังเข้าสู่ระบบ แล้วตรวจตามตารางนี้

| ID | กรณีทดสอบ | ขั้นตอน | ผลที่คาดหวัง | สถานะ |
| --- | --- | --- | --- | --- |
| JP-01 | เปิดหน้าตั้งเกม | เลือกชนิดตัวอักษรและเปิดหน้า | เห็นโหมด ชนิดตัวอักษร และรายการวรรค | รอตรวจ |
| JP-02 | เริ่มเกมปกติ | เลือก `จับคู่ตัวอักษร` แล้วกดเริ่ม | หน้าเล่นโหลดคำถามและตัวเลือกได้โดยไม่ redirect ซ้ำ | รอตรวจ |
| JP-03 | ตรวจจำนวนตัวเลือก | ดูทุกข้อระหว่างเล่น | ทุกข้อมีตัวเลือก 4 ปุ่มและไม่มีปุ่มจากข้อก่อนค้างอยู่ | รอตรวจ |
| JP-04 | ตอบถูก | กดตัวเลือกที่ถูก | ปุ่มถูกเป็นสีเขียว ปุ่มทั้งหมดถูกปิด และไปข้อถัดไป | รอตรวจ |
| JP-05 | ตอบผิด | กดตัวเลือกที่ผิด | ปุ่มที่กดเป็นสีแดง ปุ่มถูกเป็นสีเขียว แล้วไปข้อถัดไป | รอตรวจ |
| JP-06 | กดซ้ำ | คลิกหลายครั้งระหว่างรอข้อถัดไป | คะแนนเพิ่มครั้งเดียวและไม่ข้ามมากกว่าหนึ่งข้อ | รอตรวจ |
| JP-07 | จับเวลา | เล่นอย่างน้อย 5 วินาที | ตัวจับเวลาเพิ่มตามเวลาจริงและหยุดเมื่อจบเกม | รอตรวจ |
| JP-08 | จบเกม | ตอบครบทุกข้อ | แสดงคะแนน ปุ่มเล่นอีกครั้ง และบันทึกผลครั้งเดียวใน `quizzes` | รอตรวจ |
| JP-09 | ข้อมูลไม่พอ | เลือกวรรคที่มีตัวอักษรน้อยกว่า 4 ตัว | แสดงข้อความแจ้งเตือนจาก API และมีปุ่มลองใหม่ | รอตรวจ |
| JP-10 | ไม่ได้เข้าสู่ระบบ | เปิด URL หน้าเล่นโดยล้าง session | ถูกส่งไปหน้าเข้าสู่ระบบและไม่แสดงข้อสอบ | รอตรวจ |
| JP-11 | โหมดฟัง | เริ่มเกมด้วย `ฟังและจับคู่` | คำถามโหลดได้และพยายามเล่นไฟล์เสียงของข้อนั้น | รอตรวจ |
| JP-12 | มือถือ | เปิดด้วยความกว้างไม่เกิน 500px | ปุ่มตัวเลือกเรียงหนึ่งคอลัมน์ ไม่มีเนื้อหาล้นจอ | รอตรวจ |

## ทดสอบฝั่ง Admin

เปิดหน้า `backend/php/srceen/manage_choice_quiz.php` ด้วยบัญชี Admin

| ID | กรณีทดสอบ | ขั้นตอน | ผลที่คาดหวัง | สถานะ |
| --- | --- | --- | --- | --- |
| ADM-01 | สร้างชุดจับคู่ | กดเพิ่มแบบทดสอบใหม่ กรอกชื่อ เลือกชนิดตัวอักษร และเพิ่มคำถาม | บันทึกชุดชนิด `choice` สำเร็จ | รอตรวจ |
| ADM-02 | กำหนดตัวเลือก | ใส่ตัวเลือกอย่างน้อย 2 ตัว และให้มีคำตอบที่ถูกต้องอยู่ในรายการ | ระบบบันทึกโดยไม่แจ้ง validation error | รอตรวจ |
| ADM-03 | ตรวจชุดที่สร้าง | กลับหน้าจัดการแบบทดสอบตัวเลือก | เห็นชื่อชุดและจำนวนข้อที่สร้าง | รอตรวจ |
| ADM-04 | เปิดเล่นชุด Admin | เข้าหน้าเกมสมาชิกและเลือกชุดที่สร้าง | หน้าเล่นใช้คำถามและตัวเลือกที่ Admin กำหนด ไม่สุ่มชุดอื่น | รอตรวจ |
| ADM-05 | แยกชนิดตัวอักษร | สร้างชุด Katakana และ Hiragana แล้วเปลี่ยนหมวดในหน้าเริ่มเกม | รายการชุดแสดงเฉพาะชนิดที่เลือก | รอตรวจ |

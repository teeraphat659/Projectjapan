## เกณฑ์ผ่านก่อนส่งงาน

- กรณี `WR-01` ถึง `WR-21` ต้องผ่านทั้งหมด หรือมีเหตุผลและบันทึกปัญหาที่เหลือ
- ตรวจ log ของ PHP และ browser console ระหว่างทดสอบ
- ตรวจจำนวนแถวใน `writing_sessions`, `writing_attempts` และ `writing_attempt_evaluations` หลังทดสอบซ้ำ
- ทดสอบทั้ง Hiragana และ Katakana อย่างน้อยหนึ่งวรรคต่อประเภท
